句法结构：层次分析与依存分析

这一板块先回答最基础的问题：句子由哪些成分组成，哪个词支配哪个词。它只说明形式结构，不急着判断“谁是施事、谁是受事”。

Syntax
层次/成分分析把句子一层层切开：词组成短语，短语组成更大的句法单位。适合说明“把书”“放在桌子上”这样的结构块。
依存语法把句子看成词与词之间的支配关系：通常有一个核心词，其他词依附于它，说明主谓、宾语、状语、补语等关系。
为什么先看句法先看形式位置，再看语义角色。否则容易把“主语”“施事”“话题”混成同一个概念。

层层次/成分分析

先把句子按可解释的结构层级拆开，而不是直接把所有关系都归到语义角色里。

读法：先找核心谓词，再看它前后有哪些短语为它服务。

谓词角色：配价、格语法与语义角色

这一板块专门处理“动词和参与者”。配价先数动词通常需要几个核心成分；格语法说明这些成分的深层性质；语义角色把事件中的功能说清楚。

Predicate Roles
配价语法看“需要几个”一个动词为了表达完整事件，通常需要几个核心论元，就叫几价。比如“怕”通常需要经验者和刺激物，是二价。
格语法看“是什么关系”同样在句首的位置，可能是施事、经验者、处所或话题。格语法帮助我们说明这些深层关系。
语义角色看“事件功能”用施事、受事、经验者、刺激物、处所、工具、受领者等标签，解释每个成分在事件中做什么。

价什么是几价动词

“价”不是难词，可以先理解为动词需要几个核心位置。零价不用补人或物；一价通常只需要一个主体；二价需要两个参与者；三价需要三个参与者。

零价下雨了。自然事件直接成句，没有施事或受事。
一价他笑了。只需要一个主体，说明动作或状态发生。
二价李四怕狗。需要两个核心成分：经验者“李四”和刺激物“狗”。
三价妈妈送孩子一本书。需要施事、受领者和被转移的客体三个成分。

配配价语法

先数核心论元：这个动词如果要把事件说完整，哪些成分不能随便省掉？

放施事 + 受事 + 处所

读法：从核心动词出发，问“谁/什么/到哪里”等问题。

格格语法

格语法不是“格助词”的格，而是说一个成分在事件里的深层身份。

施事格 + 受事格格语法补充解释论元性质。
常见深层格施事格：动作发出者；受事格：受影响对象；处所格：事件发生位置；工具格：动作凭借的工具；经验格：心理状态的经历者。
适合解释心理动词、处所前置、工具成分、双宾结构和“把”字句中的受事突显。

角语义角色

用事件角色把“谁做、谁受影响、在哪里、用什么、给谁”等关系说清楚。

V <Agent, Patient>语义角色解释事件结构。
课堂提醒语义角色不等同于主语、宾语。它解释意义功能，句法成分解释形式位置。

汉语构式：把句子放回汉语表达系统

构式层处理“这种句子在汉语里属于什么表达模式”。它不是配价、格语法或依存语法的替代品，而是说明汉语为什么要这样安排词序和句式。

Constructions
构式是什么构式可以理解为“形式 + 意义/功能”的固定搭配。比如“把 + 受事 + 动词 + 结果/处所”常表达处置。
和配价的区别配价看动词需要几个角色；构式看整个句式怎样组织这些角色，并突出哪一部分。
为什么汉语要单独讲构式把字句、存现句、连动句、兼语句等都有明显的汉语特点，仅用主谓宾很难讲清楚。

谱常见汉语构式谱系

把字句突出受事、处置过程和结果达成。
被字句把受影响者推到前面，突出遭遇或结果，如“书被他拿走了”。
存现句从处所或时间出发，说明某处存在、出现或消失了什么。
处所句以空间场域组织信息，如“台上坐着主席团”。处所更像话题，不一定是传统主语。
连动/兼语连动句展示动作链；兼语句中一个成分同时连接前后两个谓语，如“请他来”。
述补结构用补语说明结果、趋向、程度或可能性，如“打开”“走进去”“听得懂”。

信息组织：话题、焦点与语序突显

这一板块解释说话人如何安排信息：先让学习者注意什么，重点放在哪里，哪些成分通过语序获得突显。它处理的是表达策略，不等同于句法结构。

Information Structure
话题说话先拿出来谈的对象或场域。话题不一定等于主语，如“台上坐着主席团”里的“台上”。
述题围绕话题说明的新内容。它回答“关于这个话题，说话人要告诉我们什么”。
焦点句子中最需要被注意的信息。汉语常通过语序、构式和语境来突出焦点。

焦焦点与突显

旧信息 / 新信息句首通常提供学习者容易定位的信息，后续部分推进新信息。
语序突显受事前置、处所前置或话题前置，都可能是信息组织策略。
